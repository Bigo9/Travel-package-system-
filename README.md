# Travel Package System

A command-line C++ program that helps travelers plan a full trip by combining flights, hotels, and car rentals into one package.

## Features
- Enter traveler information and budget
- Browse and select available flights
- Add hotel booking to the trip
- Add car rental to the trip
- Calculate total trip cost
- Save trip summary to a file
